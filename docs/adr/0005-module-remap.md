# ADR-0005 用户需求模块的翻译引擎重映射

- 状态：已采纳（2026-11-08）
- 决策人：交付总监 Qi

## 背景

用户原始详细需求按 7 大模块描述系统：

> 数据接入与清洗、图谱构建与存储、风险预警规则引擎与评分模型、图谱可视化检索、
> 智能投研分析（关联挖掘、相似案例、研报摘要）、服务接口层、任务调度与监控告警。

该描述实际对应文档「项目五 金融知识图谱风险预警与智能投研系统」。但用户确认按标题
构建「项目三 垂直领域专业术语机器翻译引擎」，并要求将"图谱/风险/投研"需求**舍弃或
重新对齐**。本 ADR 记录重映射方案，以保留企业级意图。

## 决策：一对一重映射

| 原需求模块 | 重映射为（翻译引擎语境） | 实现位置 |
|------------|--------------------------|----------|
| 数据接入与清洗 | 语料接入与清洗（M1） | `corpus/` |
| 图谱构建与存储 | 术语库构建与术语网络（M2） | `terminology/`（term + term_relation 即轻量图谱） |
| 风险预警规则引擎与评分模型 | 翻译质量风险规则引擎与评分（M5） | `quality/`（风险规则 + 加权风险分） |
| 图谱可视化检索 | 术语网络可视化检索 | `api/routes_viz.py` + `static/term_graph.html` |
| 智能投研分析 | 翻译智能分析：关联挖掘 / 相似错误案例 / 质量报告摘要 | `analytics/` |
| 服务接口层 | FastAPI 服务接口层 | `api/` |
| 任务调度与监控告警 | APScheduler 调度 + Prometheus 指标 + 告警 | `scheduler/` + `monitoring/` |

## 后果

- 用户列出的企业级模块全部保留，但落点在翻译引擎领域，与设计文档（项目三）一致。
- 术语网络（term_relation）即"轻量知识图谱"，支持可视化检索与关联挖掘，无需独立图库。

## 备注

如后续确实要构建「项目五 金融知识图谱」系统，可在此基础上扩展实体类型与关系类型，
架构已预留（`term`/`term_relation` 可泛化为通用节点/边模型）。
