# ADR-0003 语料接入与清洗策略（模块 M1）

- 状态：已采纳（Phase 1）
- 日期：2026-11-08

## 背景
通用大模型在垂直领域术语翻译准确率 <60%，根因之一是训练/评测语料含噪声（HTML、控制符、
未翻译副本、长度失配）。需一套确定性、可审计、可回归的清洗管线。

## 决策
1. **确定性优先**：相同输入永远得到相同输出，不使用随机或外部模型，保证可审计与可回归测试。
2. **不吞数据**：单条脏数据返回 `CleanResult(valid=False)` + 原因列表，由调用方决定丢弃或降级，
   批量任务不因单条坏数据中断。
3. **质量评分多维加权**：Unicode 归一化、HTML/控制符剥离、空白折叠、长度比（合理平台区
   [0.2,2.5] + 边缘线性衰减）、字符集一致性（源拉丁/目标 CJK 为合理；同语系=未翻译硬失效）、
   标点平衡。综合分 0~1，<0.25 判无效。
4. **硬失效信号**：源目标归一化后完全相同 → `identical_src_tgt`；源目标同属拉丁语系 →
   `untranslated_same_script`。二者直接判无效，避免漏译进入术语抽取与训练。
5. **来源溯源**：每次文件接入登记 `SourceProvenance`，记录接受/拒绝/低质量计数与文件路径。

## 影响
- 术语抽取（Phase 2）与训练数据准备（Phase 3）只能消费 `valid` 且质量分达标的语料。
- 质量阈值为可配置项（`CleaningConfig`），可按领域微调。

## 替代方案
- 用 LLM 做清洗：成本高、非确定性、不可审计，否决。
- 仅正则去噪不做质量评分：无法区分"可入库"与"需人工校核"，否决。
